【任务】
请用 Three.js 创建一个可运行的桌面微缩铁路小镇，具有实体沙盘、手工模型般的质感，不采用体素风格。

【场景要求】
1. 场景放在一块有厚度、边框的展示底座上，采用适合看清全貌的等距或近似等距视角。
2. 围绕闭合铁路组织出一个完整、可辨认的微缩小镇。应包含车站、建筑群、河流与铁路跨河结构，并通过树木、道路、路灯等元素形成有层次的聚落环境。建筑的数量、类型、尺度、密度与分布由你根据整体构图自行决定，不以凑固定数量为目标。
3. 轨道连接连续，跨河位置与桥梁结构关系合理，建筑不妨碍铁路运行。道路应自然联系车站与主要建筑区域，让小镇看起来是被整体规划出来的，而不是把若干独立模型简单摆在底座上。
4. 一列火车由一节车头和两节车厢组成。每节车厢分别沿轨迹行驶，转弯时保持合理间距和朝向，不能把整列车当成一个刚体绕中心旋转。
5. 默认是有暖色阳光和投影的傍晚，木底座、草地、水面与模型建筑材质可辨认；打开页面即可看到全沙盘和运行的列车。

【交互要求】
1. 提供运行／暂停、速度调节和复位。暂停时车厢与到站计时都暂停。
2. 火车每次抵达车站停留约两秒，再继续运行，不要求上下客动画。
3. 提供白天／夜晚切换；夜晚车站、路灯和部分窗户发光，场景仍可看清。
4. 支持旋转、缩放，复位后恢复确定的初始机位、列车位置与速度。

【实现取向】
优先保证沙盘整体构图、闭合轨道与列车连续运动的可信感。小镇中的道路、植被、灯光、建筑细节和其他微缩元素可以自由取舍或扩展；额外机制并非必需，但如果加入，应服务于“桌面微缩铁路镇”的整体观感与稳定运行。

【技术要求】
- 使用 Three.js 完成核心 3D 沙盘，React 或原生实现均可，无需后端。
- 在工作区创建完整前端项目，可使用 Vite 等常见构建工具，确保安装后可以直接启动和构建。
- 列车运动、场景组织、材质与优化方式可自行选择；列车运行和视角操作应保持稳定流畅。
- 页面打开后直接看到完整沙盘和默认运行状态。

【交付要求】
- 交付完整项目，并在 README 或项目说明中写明安装、启动和必要的使用方式。
- 如果实际执行了构建、运行或功能验证，请如实说明结果；没有验证的部分无需写成已经通过。

做好以后单独额外整合，构建单独一个以你设计的作品名命名的 HTML 文件。
